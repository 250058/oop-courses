VS Code · Jupyter

VS Code에서 주피터 노트북 만들고 다루기

.ipynb 파일을 새로 만들어 실행하는 절차와, 셀 작업을 더 편하게 만들어주는 확장 프로그램을 정리했습니다. 로컬 파이썬 환경(가상환경)에 커널을 연결해 운영하는 방법도 함께 담았습니다.

1. 노트북 만들고 실행하기

Python 확장과 인터프리터만 준비되어 있으면 별도의 Jupyter 설치 없이도 VS Code 안에서 바로 노트북을 실행할 수 있습니다.

01

Python 확장 설치 & 인터프리터 선택

마켓플레이스에서 Python(ms-python.python)을 설치합니다. Jupyter 관련 확장은 이 확장을 설치하는 순간 함께 딸려 들어옵니다.

Ctrl+Shift+P → Python: Select Interpreter로 노트북에서 사용할 파이썬 환경(가상환경, 콘다, 도커 컨테이너 등)을 지정합니다.

02

새 노트북 만들기

Ctrl+Shift+P → Create: New Jupyter Notebook을 실행하거나, 탐색기에서 확장자가 .ipynb인 파일을 직접 만들면 됩니다. 저장할 때는 Ctrl+S로 그대로 저장하면 됩니다.

03

커널 선택

노트북 우측 상단의 커널 선택기에서 실행에 쓸 커널을 고릅니다. ipykernel이 없는 환경을 고르면 VS Code가 설치를 제안합니다.

04

셀 작성 & 실행

셀 하나는 코드 또는 마크다운입니다. 셀 좌측 하단의 언어 선택기로 전환할 수 있습니다.

동작단축키
현재 셀 실행Ctrl+Enter
실행 후 아래 새 셀 삽입Shift+Enter
실행 후 커서 유지, 새 셀 삽입Alt+Enter
전체 실행 / 이 셀 이전(이후) 전체 실행툴바의 Run All 계열 메뉴
05

변수 탐색기 & 데이터 뷰어

셀을 한 번 실행한 뒤 툴바의 Variables 아이콘을 누르면 현재 값을 가진 변수 목록이 뜹니다. 표 형태 데이터는 더블클릭하면 정렬·필터가 되는 데이터 뷰어로 열립니다.

06

디버깅

ipykernel 6 이상이면 Run by Line(한 줄씩 실행)과 Debug Cell(중단점을 건 전체 디버거) 두 가지 방식을 셀 툴바에서 바로 쓸 수 있습니다.

🐍 로컬 파이썬 환경에 커널 연결하기

실습마다 독립된 가상환경을 쓰고 있다면, 그 환경을 그대로 노트북 커널로 등록해서 씁니다.

  1. 터미널에서 가상환경 생성 & 활성화: python -m venv .venv
  2. 활성화한 상태에서 커널 패키지 설치: pip install ipykernel
  3. 커널 선택기에서 해당 .venv 인터프리터를 고르면 VS Code가 필요한 커널 등록을 자동으로 처리합니다

여러 실습 환경을 번갈아 쓴다면 python -m ipykernel install --user --name=실습환경이름으로 이름을 지정해두면 커널 선택기에서 구분하기 쉽습니다.

2. 추천 확장 프로그램

Jupyter 확장을 설치하면 4개가 자동으로 딸려 옵니다. 나머지는 필요에 따라 골라 설치하면 좋은 것들입니다.

Jupyter 설치 시 자동 포함 따로 설치하면 좋음
Pythonms-python.python
필수

인터프리터 선택, 린팅, Pylance를 포함해 파이썬 작업 전반의 기반이 되는 확장. 이게 있어야 노트북도 동작합니다.

Jupyterms-toolsai.jupyter
필수

.ipynb 편집, 셀 실행, 인터랙티브 창을 담당하는 핵심 확장. 아래 4개를 함께 설치합니다.

Jupyter Keymapms-toolsai.jupyter-keymap
자동 포함

고전 Jupyter와 동일한 단축키 배치를 그대로 씁니다.

Jupyter Notebook Renderersms-toolsai.jupyter-renderers
자동 포함

LaTeX, Plotly, Vega 같은 출력 형식을 노트북 안에서 바로 렌더링합니다.

Jupyter Cell Tagsms-toolsai.vscode-jupyter-cell-tags
자동 포함

셀에 태그를 달아 파이프라인 도구(예: papermill)와 연동할 때 유용합니다.

Jupyter Slide Showms-toolsai.vscode-jupyter-slideshow
자동 포함

셀 단위로 슬라이드 유형을 지정해 노트북을 발표 자료로 내보낼 수 있게 해줍니다.

Pylancems-python.vscode-pylance
자동 포함

Python 확장에 딸려오는 언어 서버. 노트북 셀에서도 자동완성·타입 힌트가 그대로 동작합니다.

Data Wranglerms-toolsai.datawrangler
추천

데이터프레임을 표로 보면서 필터·정렬·결측치 처리를 클릭만으로 하고, 그 과정을 코드로도 받을 수 있습니다.

Python Environment Managerdonjayamanne.python-environment-manager
추천

사이드바에서 로컬 venv·conda 환경 목록을 한눈에 보고 만들기·삭제·패키지 설치까지 처리합니다.

Jupyter PowerToysms-toolsai.vscode-jupyter-powertoys
실험적

Jupyter 팀이 미리 써보게 공개한 실험적 기능 모음. 정식 기능이 되기 전 미리 체험하고 싶을 때만 설치하면 됩니다.

Microsoft 공식 문서(code.visualstudio.com)와 VS Code Marketplace의 Jupyter 확장 페이지를 바탕으로 정리했습니다.
